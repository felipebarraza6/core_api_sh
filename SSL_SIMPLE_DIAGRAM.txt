╔══════════════════════════════════════════════════════════════════════════════╗
║                         ¿POR QUÉ 3 CERTIFICADOS?                            ║
╚══════════════════════════════════════════════════════════════════════════════╝

   Porque Cloudflare está "en el medio" actuando como proxy:

   Usuario ←─[Cert #1]─→ Cloudflare ←─[Cert #2]─→ Servidor

   Cloudflare necesita:
   • Un certificado para hablar con el usuario (Cert #1) ✅
   • Verificar que el servidor es legítimo (Cert #2 o #3) ⚠️

   Sin Cert #2/#3 → Cloudflare no confía → Error 525


╔══════════════════════════════════════════════════════════════════════════════╗
║                    ¿QUÉ HACER CON ERROR 525?                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

   OPCIÓN A: No hacer nada (si solo usas correos)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   ✅ El error NO afecta emails
   ✅ El error NO afecta api.smarthydro.app
   ❌ Los visitantes de smarthydro.app verán error 525

   OPCIÓN B: Instalar SSL en cPanel
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   1. Entrar a cPanel
   2. Buscar "SSL/TLS Status" o "AutoSSL"
   3. Click "Run AutoSSL" para smarthydro.app
   4. Esperar 2-5 minutos
   ✅ Error 525 desaparece
   ✅ smarthydro.app funciona (aunque esté vacío)

   OPCIÓN C: Cambiar Cloudflare a modo "Flexible"
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Dashboard → SSL/TLS → "Flexible"
   ✅ Error 525 desaparece
   ⚠️ Conexión Cloudflare → cPanel sin encriptar (HTTP)
