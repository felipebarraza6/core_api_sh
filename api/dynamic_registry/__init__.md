# 📱 Dynamic Registry (Server-Driven UI)

**Responsabilidad**: Controlar la interfaz de usuario desde el Backend.
**Estado**: ✅ ACTIVO

## 🧠 Propósito
Permitir cambiar formularios, menús y flujos de la App Móvil/Web sin tener que volver a compilar/desplegar el Frontend.

## 📦 Funcionalidad
*   **JSON Schema Forms**: Define qué campos muestra el formulario de "Nuevo Punto" según el cliente.
*   **Menu Registry**: Define qué botones ve el usuario (ej: Ocultar "Compliance" a usuarios técnicos).
