# Scripts de Deployment

Scripts para despliegue en diferentes entornos (desarrollo, producción) y monitoreo.

## Archivos

- `deploy.dev.sh` - Deploy en entorno de desarrollo
- `deploy.production.sh` - Deploy en producción (versión actual)
- `deploy_production.sh` - Deploy en producción (versión legacy)
- `monitor.production.sh` - Monitoreo del entorno de producción
