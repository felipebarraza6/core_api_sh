# Scripts de Mantenimiento

Scripts para mantenimiento del sistema, backups y análisis del cluster.

## Archivos

- `backup_cluster.py` - Realizar backup del cluster de PostgreSQL
- `analyze_cluster.py` - Analizar estado del cluster
- `sync_cluster_to_local.py` - Sincronizar cluster a base de datos local
- `core_backup_sync_run.sh` - Script principal de backup y sincronización
- `README_LIMPIEZA.md` - Guía de limpieza y mantenimiento
