# Scripts de Migración

Scripts para migración de datos entre versiones y limpieza de código legacy.

## Archivos

- `migrate_novus_points.py` - Migración de puntos Novus al sistema dinámico
- `migrate_twin_points.py` - Migración de puntos Twin al sistema dinámico
- `migrate_cronjob_example.py` - Ejemplo de migración de cronjobs
- `cleanup_old_getters.py` - Limpieza de getters antiguos del código
