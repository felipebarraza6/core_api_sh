Documentación SmartHydro API

API REST de monitoreo hidrológico en tiempo real. Expone endpoints para ingestar telemetría desde sensores IoT, gestionar puntos de captación, configurar alertas inteligentes, generar reportes regulatorios DGA/SMA y consultar históricos de consumo. ¿Qué es esta API?

Una introducción para quienes se conectan por primera vez.

🔌

Una API es el puente

La API permite que tu aplicación o sistema interno se comunique con el motor de monitoreo. Es la interfaz por donde entran y salen datos: telemetría, alertas, reportes y configuraciones. Todo via HTTP con respuestas en JSON.

📡

Qué entrega esta API

Datos de caudal, nivel y volumen acumulado desde sensores instalados en pozos, ríos y canales. También gestiona alertas, reportes regulatorios (DGA/SMA), usuarios y tickets de soporte. Todo via HTTP con respuestas en formato JSON.

👤

Quién la usa

Desarrolladores que integran telemetría en plataformas de clientes, consultoras ambientales que automatizan reportes, y equipos internos que necesitan extraer datos para análisis o Business Intelligence.

🛡️

Cómo se protege

Toda comunicación usa HTTPS. Para acceder se requiere un token Bearer que se obtiene al hacer login. Cada token tiene un tiempo de expiración y puede revocarse. Los endpoints sensibles están protegidos por autenticación.

Empezar en 3 pasos

Conexión a la API en menos de 5 minutos.

1

Obtener token de acceso

Envía tus credenciales al endpoint de login. Recibirás un access_token JWT.

# Login (Ikolu optimized) curl -X POST https://api.smarthydro.app/api/ik/login/ \\ -H "Content-Type: application/json" \\ -d '{"email":"tu@email.cl","password":"***"}'
2

Hacer tu primera llamada

Incluye el token en el header Authorization: Bearer <token>.

# Listar tus puntos de captación curl -X GET https://api.smarthydro.app/api/ik/points_summary/ \\ -H "Authorization: Bearer eyJ..."
3

Explorar funcionalidades

Consulta telemetría, configura alertas, descarga reportes o gestiona tickets de soporte.

# Últimos 7 días de un punto curl -X GET "https://api.smarthydro.app/api/ik/point/42/calendar/?days=7" \\ -H "Authorization: Bearer eyJ..."

Conceptos Clave

Entiende el dominio antes de integrar.

📍

Punto de Captación

Ubicación física donde se mide agua (río, pozo, canal). Tiene un dispositivo de telemetría asociado que envía datos periódicamente.

📡

Telemetría

Datos enviados automáticamente por sensores: caudal (L/s), nivel (m), total acumulado (m³), y estado de conexión.

⚠️

Alerta (AlertRule)

Regla configurable que monitorea un punto. Puede detectar: umbral superado, desconexión, reconexión o errores de procesamiento.

📊

DGA / SMA

Compliance regulatorio chileno. DGA = Dirección General de Aguas. SMA = Superintendencia del Medio Ambiente. La API envía datos automáticamente según estándar (Mayor, Medio, Menor).

🎫

Ticket de Soporte

Solicitud de ayuda técnica vinculada a un punto. Incluye comentarios, adjuntos, asignación y seguimiento de estado.

📈

Reporte

Exportación de datos en Excel o JSON por proyecto, punto o período. Incluye consumos, caudales, niveles y estadísticas.

Glosario

Términos del dominio hidrológico y técnico.

Caudal
Volumen de agua que pasa por una sección en un tiempo determinado. Medido en litros por segundo (L/s).
Counter Reset
Evento en que el contador de pulsos de un sensor vuelve a cero (por reinicio, cambio de batería o desbordamiento).
DGA
Dirección General de Aguas. Entidad reguladora chilena que exige reportes periódicos de extracción de agua.
InteractionDetail
Registro individual de telemetría. Contiene fecha, caudal, nivel, total, variables y metadatos de procesamiento.
Nivel
Altura del agua medida desde un punto de referencia. Medido en metros (m).
Punto de Captación
Ubicación física donde se extrae o mide agua. Puede tener múltiples variables (caudal, nivel, total).
Pulso
Señal eléctrica generada por el sensor por cada unidad de volumen medida. Se convierte a m³ mediante un factor.
SMA
Superintendencia del Medio Ambiente. Entidad fiscalizadora que también recibe reportes de extracción de agua.
Telemetría
Transmisión automática de datos desde sensores en campo hacia el servidor central.
Totalizado
Volumen acumulado de agua extraída desde el inicio de la medición. Medido en metros cúbicos (m³).
Variable
Magnitud medida por un sensor. Tipos: TOTALIZADO (pulsos), CAUDAL (L/s), NIVEL (m), CAUDAL_PROMEDIO.
Esquema (Scheme)
Configuración de variables asociadas a un punto. Define qué sensores tiene y cómo se procesan.
