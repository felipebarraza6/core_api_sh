📋 Acerca de este documento

Este catálogo no es una guía de ventas. Es un traductor técnico-comercial de un API de monitoreo hidrológico: cada sección describe lo que esta API puede entregar, cómo se configura en el sistema y qué recibe el cliente final. La gama es amplia — en la práctica, la diferencia entre una propuesta y otra radica principalmente en la frecuencia de telemetría, las variables medidas y el nivel de cumplimiento requerido.

Documento creado por Felipe Barraza — Líder de Software, SmartHydro.

🔗 Agregación de puntos DGA

El sistema permite configurar que un punto sume (agregue) los totales de otros puntos al momento de generar el reporte DGA. Esto es útil cuando un cliente tiene múltiples pozos bajo una misma resolución. La agregación se configura en el campo dga_aggregate_points.

Menú de Software

Capacidades de la plataforma que el cliente puede contratar. Cada funcionalidad se activa o desactiva independientemente.

Portal Web

📊 Dashboard multi-proyecto

Vista consolidada de todos los puntos del cliente. KPIs: puntos activos, alertas pendientes, total acumulado del mes, caudal promedio.

🗺️ Mapa de puntos

Geolocalización de cada punto de captación. Clic en un punto muestra resumen en vivo: caudal, nivel, total y estado de conexión.

📈 Histórico y gráficos

Vistas de 7 días, 30 días, 90 días y personalizadas. Tendencias de caudal, nivel y consumo. Exportación a CSV/Excel.

📁 Gestión documental

Archivos asociados a cada punto con tipos configurables: permisos, resoluciones, fotos, certificados.

App Móvil Ikolu

La app móvil Ikolu consume los mismos endpoints que el portal web. Su funcionalidad se organiza en 7 módulos suscriptibles por punto:

Módulo Nombre Qué muestra Disponibilidad
m1 Mi Pozo Resumen en vivo del punto: caudal, nivel, total, estado Incluido siempre
m2 DGA Reportes DGA descargables, estado de envíos, comprobantes Suscripción opcional
m3 Datos y Reportes Tablas de datos históricos, exportación Excel/PDF Suscripción opcional
m4 Gráficos Visualización temporal de variables, comparativas Suscripción opcional
m5 Indicadores KPIs calculados: eficiencia, cumplimiento, tendencias Suscripción opcional
m6 Alarmas Alertas en tiempo real, historial de eventos Suscripción opcional
m7 Documentos Acceso a archivos del punto desde el móvil Suscripción opcional

APIs disponibles

🔌 API Legacy /api/

REST completo con DefaultRouter. CRUD de puntos, lecturas, alertas, reportes. Incluye throttling por endpoint para control de uso.

🔌 API Ikolu /api/ik/

Endpoints batch optimizados para móvil: batch/telemetry/, batch/stats/, login/. Menos llamadas, menos datos transferidos.

Reportes generados por el sistema

📊 Excel DGA

Reporte formateado listo para envío a la DGA. Incluye caudal promedio horario, total acumulado, código DGA, SHAC, región.

📄 PDF

Reporte visual para presentaciones internas o auditorías. Incluye gráficos y tablas resumen.

📰 Boletín diario

Resumen automático enviado cada mañana con el estado de todos los puntos, alertas activas y totales del día anterior.

📅 Reportes programados

Reportes personalizados con frecuencia configurable (diaria, semanal, mensual) y destinatarios múltiples.

Módulos Ikolu y Periodicidades

Cada punto puede suscribir módulos de la app móvil de forma independiente. El módulo m1 es obligatorio; los demás son opcionales.

Módulo Nombre Descripción Obligatorio Periodicidades
m1 Mi Pozo Resumen en vivo: caudal, nivel, total, estado de conexión Sí —
m2 DGA Reportes DGA descargables, estado de envíos, comprobantes No Mensual, Trimestral, Semestral, Anual
m3 Datos y Reportes Tablas históricas, exportación Excel/PDF No Mensual, Trimestral, Semestral, Anual
m4 Gráficos Visualización temporal, comparativas entre períodos No Mensual, Trimestral, Semestral, Anual
m5 Indicadores KPIs calculados: eficiencia, cumplimiento, tendencias No Mensual, Trimestral, Semestral, Anual
m6 Alarmas Alertas en tiempo real, historial de eventos No Mensual, Trimestral, Semestral, Anual
m7 Documentos Acceso a archivos del punto desde el móvil No Mensual, Trimestral, Semestral, Anual

📝 Sobre las suscripciones

Cada módulo opcional (m2-m7) tiene una fecha de inicio de suscripción y una periodicidad. El sistema permite activar o desactivar módulos en cualquier momento. Al desactivar, el módulo deja de aparecer en la app pero los datos históricos se mantienen.

Glosario Técnico-Comercial

Traducción de términos del sistema a términos que aparecen en una propuesta comercial.

Término técnico Traducción comercial
Frecuencia de telemetría Cada cuánto tiempo llega un dato al sistema (1, 5, 10, 15, 30, 60 minutos)
Variable caudal Litros por segundo (L/s) instantáneo, calculado desde pulsos del sensor
Variable total Metros cúbicos (m³) acumulados desde el inicio del monitoreo
Variable nivel Metros (m) de profundidad del agua en el pozo, requiere sensor adicional
DGA Mayor Reporte horario obligatorio a la Dirección General de Aguas. Requiere frecuencia ≤ 10 min.
DGA Medio Reporte diario obligatorio a la DGA. Requiere frecuencia ≤ 60 min.
SMA Reporte mensual/semestral al Servicio de Evaluación Ambiental. Usa los mismos sensores que DGA.
Software-Only Plataforma sin sensores: el cliente ingresa datos manualmente y descarga reportes.
Sensor de pulsos Dispositivo que cuenta revoluciones del medidor de agua. Base para caudal y total.
Sensor de nivel Dispositivo de presión o ultrasonido que mide la altura del agua en el pozo.
Alerta de umbral Notificación automática cuando una variable supera o baja de un valor configurado.
Alerta de desconexión Notificación cuando el sensor deja de comunicarse con la plataforma.
Retry persistente Si un envío a DGA falla, el sistema lo reintenta automáticamente hasta que llegue.
API Legacy Interfaz de programación REST completa para integrar esta API con otros sistemas.
API Ikolu Interfaz optimizada para la app móvil. Endpoints batch que reducen tráfico de datos.
White-label La plataforma se muestra con el logo y colores de la consultora o cliente.
Boletín diario Email automático cada mañana con el resumen del estado de todos los puntos.
Agregación de puntos Sumar los totales de varios pozos para reportar a DGA como un solo punto.
Modo FORM Ingreso manual de datos por el cliente desde web o app.
Modo TELEMETRY Datos que llegan automáticamente desde el sensor vía internet.
